# Linux Kernel Daily

每日 Linux 核心機制深入解析，由 AI 自動生成並推送。

## 閱讀方式

- **GitHub Pages**: https://Aiden128.github.io/linux-kernel-daily/
- **原始檔案**: https://github.com/Aiden128/linux-kernel-daily/tree/main/daily

## 內容格式

每篇文章以 Markdown 格式存放於 `daily/YYYY-MM-DD.md`，包含：
- 主題概述
- 原始碼層級分析（檔案路徑、函式名稱、資料結構）
- 設計原理與 rationale
- 繁體中文撰寫
